# TikTok Telegram Downloader Bot

1. Fur bot.py.
2. Ku beddel GELI_TOKEN_KAAGA_HALKAN token-ka cusub ee @BotFather; ama si ammaan badan ugu deji Railway Variables magaca TELEGRAM_BOT_TOKEN.
3. Railway wuxuu rakibayaa requirements.txt, kadibna wuxuu bilaabayaa bot.py.
4. Telegram ka fur bot-kaaga oo dir /start.

Isticmaal kaliya muuqaallo aad leedahay ama aad fasax u haysato inaad soo dejisato. Bot-ku ma dhaafo private/restricted content.
